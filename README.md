## 关注什么

以可检查的 Agent Memory 工程实现为核心，兼顾有代码的研究工作和评测基准。覆盖跨会话记忆、Coding Agent 记忆插件、记忆检索与组织、压缩与遗忘、经验复用以及记忆评测。准确范围以确认后的配置为准。

## 如何阅读未来更新

首页只显示当前摘要与入口；结构化数据保存观测事实，项目卡片说明实现与局限，周报解释变化。关注度、技术变化和工程可用性分开表达，不把 Star 数量等同于质量，不把 GitHub 官方 Trending 当作唯一数据来源。

当前仓库不包含已运行的采集器、CI 或历史快照。后续启用前须完成配置确认、基线采集、重复运行测试、写入后回读检查，以及首个定时运行的端到端验收。

## 自动化边界

仅允许更新 `psiQAQ/agent-memory-github-trending`。不访问无关私有仓库，不发布对话历史或个人资料，不运行被追踪项目的代码，不额外购买服务或使用付费 API。正常数据更新由 GPT 维护；扩大权限、改变跟踪目标或引入费用须重新确认。

此仓库不是 GitHub 官方榜单，不提供项目安全性或性能的独立认证。
